Neural Network Atlas ①27 from the original chart

Core question · What is each of the 27 neural networks, drawn only with circles and lines, built to do?

Stefan Leijnen and Fjodor van Veen compiled the neural network structure chart “The Neural Network Zoo,” which includes 27 structures. This page redraws each of the 27 and goes through, one by one, what it does and what it is strong and weak at. Battles and scoring are covered later, on pages 3 and 4.

Before reading

This chart only drew the “wiring diagram”

The original for this atlas is the neural network structure chart “The Neural Network Zoo,” compiled by Leijnen and van Veen[5]. The original chart shows only cell (node) types and connecting lines. Activation functions (how signals are bent), loss functions (what counts as an error), learning methods (how weights get adjusted), and data amounts are all left out, as if fixed. The comparisons in this atlas follow the same assumption: we ask "which tasks does the connection structure alone favor, if all other conditions are equal."

A few models, however, are distinguished not by structure but by those missing elements. For example, RBF has the same diagram as FF and differs only in its activation function. Such models are marked on their cards as difference not shown in the diagram.

Cell legend for the structure diagrams

The three bars under each card (expressiveness, training stability, current use) are judged values assuming equal conditions. Actual performance varies greatly with data and task.

1Feedforward

Basic feedforward networks

4 types1 difference not shown in the diagram

Signals flow in only one direction, from input to output. This is the starting point of every neural network.

In the fruit fly

A fruit fly's sensory neuron takes in a smell signal and fires once it crosses a threshold. Each synapse has a different transmission strength.

In the neural network

Each input is multiplied by a weight, summed, bent by an activation function, and passed to the next layer. The weights correspond to synaptic strength.

Limits of the analogy: a real neuron's voltage rises and falls over time, but this network computes once and is done.

Limit of this group · It does not remember order. Inputs that came in earlier do not carry into the next calculation.

Doctor

Let's start with the simplest one. The other 26 are all this, with something added on top.

2Recurrent

Recurrent networks and memory

3 types

The output loops back to itself (the loop at the top of the structure diagram). Handles order and time.

In the fruit fly

The fruit fly central complex has a circuit that keeps track of head direction in a ring pattern.

In the neural network

The hidden state is passed to the next time step through a loop connection, carrying the past along.

Limits of the analogy: ring circuits and recurrent connections are alike only in that they 'maintain a state'.

Limit of this group · It reads one step at a time, which is slow, and very distant past still fades.

Assistant Haru

LSTM and GRU are still widely used as baseline models for process sensor data.

3Autoencoder

Autoencoder family

4 types2 differences not shown in the diagram

The input is compressed through a narrow passage and then expanded again, learning to reconstruct the original input.

In everyday terms

It is like summarizing a long text in one line and then practicing expanding it back into the original.

In the neural network

The encoder compresses and the decoder expands. If reconstruction works well, the essentials were kept.

Limits of the analogy: the summary analogy captures only the process. In reality it is optimization that shrinks the reconstruction error numerically.

Limit of this group · It reconstructs well, but recalling one stored memory from a fragment needs a separate associative ability.

Fruit Fly Researcher

Don't assume it has understood just because it reconstructs well. Try it on inputs it has never seen.

4Energy

Energy and probability models

5 types1 difference not shown in the diagram

Units are connected with no layer structure, or cells switch on and off probabilistically. These were the leading lights of the early days of deep learning.

In the fruit fly

The fruit fly mushroom body stores memory with a sparse pattern in which only some Kenyon cells switch on for any single odor.

In the neural network

Hopfield and Boltzmann networks turn stored patterns into 'low-energy valleys' and roll toward them.

Limits of the analogy: there is no evidence that mushroom body memory works by minimizing energy. It shares only the sparse-pattern feature.

Limit of this group · Learning is slow and hard to scale up. That is why large inputs like images needed other structures.

Assistant Haru

Boltzmann machines are a beautiful theory, but once you time their training, you sigh.

5Convolutional

Convolutional neural network

3 types

A pink kernel slides a small window and groups only neighboring pixels together. The same window is reused across the whole image.

In the fruit fly

Beneath the fruit fly compound eye, the medulla has repeating columns of circuitry with the same shape.

In the neural network

A single convolution filter slides across the entire image using the same weights (weight sharing).

Limits of the analogy: repeating columns and weight sharing only resemble each other. The fruit fly visual system does not learn through backpropagation.

Limit of this group · It sees neighbors well, but relationships between distant pixels take many stacked layers to notice, and do so late.

Doctor

Reusing one small window across the whole picture greatly reduces the values to learn.

6Special

Generative and special structures

8 types6 differences not shown in the diagram

These are structures with unusual learning methods or connection schemes. The original chart grouped them together.

In everyday terms

Like a forger and an appraiser locked in a contest (GAN), an echoing cave (ESN), or an elevator beside the stairs (DRN), each has its own unique mechanism.

In the neural network

For most of them, the identity lies in a training method not shown in the diagram. Check the card's 'difference not shown in the diagram' too.

Limits of the analogy: each analogy fits only one structure. There is no common principle that applies to the whole group.

Limit of this group · After the chart came out, Transformers, which use attention, changed the landscape for language and images. We continue on the next page.

Fruit Fly Researcher

The DRN shortcut is in most models today. A small device that has survived a long time.
